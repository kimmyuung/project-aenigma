# Aenigma 머더 미스터리 게임 규칙

## 1. 게임 개요

**Aenigma**는 온라인 머더 미스터리 게임으로, 플레이어들이 각자의 역할을 맡아 사건의 진상을 추리합니다.

- **플레이어 수**: 4~10명
- **게임 시간**: 시나리오에 따라 30분~2시간
- **GM(Game Master)**: Discord를 통해 게임 진행 관리

---

## 2. 역할 (Roles)

### 필수 역할
| 역할 | 설명 | 목표 |
|------|------|------|
| **범인 (CRIMINAL)** | 사건의 진범 | 의심받지 않고 투표에서 살아남기 |

### 시나리오별 선택 역할
| 역할 | 설명 | 목표 |
|------|------|------|
| **탐정 (DETECTIVE)** | 사건을 조사하는 특수 역할 | 범인을 찾아내기 (시나리오에 따라 존재 여부 결정) |

### 기본 역할
| 역할 | 설명 | 목표 |
|------|------|------|
| **용의자 (SUSPECT)** | 일반 참가자 | 범인을 찾아 투표로 지목하기 |

> **참고**: 역할 구성은 시나리오에 정의됩니다. 탐정이 없는 시나리오도 있습니다.

---

## 3. 게임 진행 (Phases)

```
INTRO → LOBBY → INVESTIGATION (1~3라운드) → FINAL_VOTE → CONCLUSION → FINISHED
```

### 3.1 INTRO (도입)
- 시나리오 배경 설명
- 사건 개요 공개

### 3.2 LOBBY (역할 숙지)
- 각 플레이어에게 개인 역할 및 단서 전달
- GM 질문 시간
- 역할에 대한 질문/확인

### 3.3 INVESTIGATION (조사 시간)
- **라운드 수**: 1~3라운드 (GM이 설정)
- 플레이어 간 대화를 통해 정보 수집
- 단서 공유 및 추리

### 3.4 FINAL_VOTE (최종 투표)
- 모든 플레이어가 범인을 지목
- 최다 득표자가 범인으로 지목됨

### 3.5 CONCLUSION (결과 발표)
- 진범 공개
- 승패 결정

### 3.6 FINISHED (게임 종료)
- 게임 데이터 저장
- 통계 업데이트

## 4. 채팅 규칙

### 4.1 채팅 유형
| 유형 | 설명 | 특징 |
|------|------|------|
| **공개 채팅 (PUBLIC)** | 모든 플레이어에게 표시 | 거짓말 가능, 단서 "설명"만 가능 |
| **밀담 (WHISPER)** | 특정 플레이어에게만 전송 | 실제 단서 공유 가능, 1:1 비밀 대화 |
| **시스템 (SYSTEM)** | GM/시스템 공지 | 게임 진행 안내 |

### 4.2 플랫폼별 채팅
| 플랫폼 | 공개 채팅 | 밀담 |
|--------|----------|------|
| **웹 프론트엔드** | 공개 채팅창 | 플레이어 선택 → 귓속말 |
| **Discord** | 게임 텍스트 채널 | DM (개인 메시지) |

> **양방향 동기화**: 웹에서 보낸 메시지는 Discord에, Discord에서 보낸 메시지는 웹에 표시됩니다.

### 4.3 단서 공유 규칙
- ✅ **밀담에서**: 단서 원문 공유 가능
- ⚠️ **공개 채팅에서**: 단서에 대한 말만 가능 (거짓말 가능!)

> **전략 포인트**: 공개 채팅에서 누군가 단서를 언급해도 진실인지 거짓인지 알 수 없습니다.

### 4.4 Discord 음성채팅

#### 채널 구성
```
Discord 서버
├── 📝 텍스트 채널
│   ├── #공개-채팅     ← 텍스트 기록 (웹과 동기화)
│   └── #시스템-공지   ← GM 공지
│
└── 🔊 음성 채널
    ├── 🎤 전체 토론    ← 공개 대화
    └── 🔇 밀담실 1~N   ← 1:1 비밀 대화
```

#### 페이즈별 음성채널 사용
| 페이즈 | 음성 채널 | 설명 |
|--------|----------|------|
| **LOBBY** | 전체 토론 | 역할 숙지, GM 질문 |
| **INVESTIGATION** | 전체 토론 + 밀담실 | 공개 토론 및 1:1 밀담 |
| **FINAL_VOTE** | 전체 토론 | 최종 변론, 투표 |

#### 밀담실 사용 규칙
- 밀담 시 **밀담실 음성채널**로 이동
- 다른 플레이어들은 **"누가 밀담 중인지"** 볼 수 있음 → 심리전 요소
- 밀담 종료 후 **전체 토론**으로 복귀

> **팁**: 밀담실 이동은 다른 플레이어에게 보이므로, 의도적으로 이동하여 상대를 긴장시키는 전략도 가능합니다.

## 5. 단서 시스템 (Clues)

### 5.1 단서 유형
| 유형 | 설명 |
|------|------|
| **개인 단서** | 특정 역할에게만 주어지는 단서 |
| **공개 단서** | 조사 중 발견되는 공통 단서 |

### 5.2 단서 획득
- LOBBY 페이즈: 역할과 함께 개인 단서 지급
- INVESTIGATION 페이즈: 조사 활동으로 공개 단서 획득

---

## 6. 투표 시스템

### 6.1 투표 규칙
- FINAL_VOTE 페이즈에서만 투표 가능
- 살아있는 플레이어만 투표 가능
- 각 플레이어는 1표만 행사
- 자기 자신에게 투표 불가

### 6.2 결과 판정
- 최다 득표자가 범인으로 지목됨
- 동률일 경우: 추가 토론 후 재투표 또는 GM 판정

---

## 7. 승리 조건

### 시민 팀 (용의자 + 탐정)
- **승리**: 투표로 범인을 정확히 지목

### 범인
- **승리**: 투표에서 지목되지 않고 생존

---

## 8. GM (Game Master) 역할

### Discord 슬래시 명령어
| 명령어 | 설명 |
|--------|------|
| `/game start` | 게임 시작 |
| `/game phase <phase>` | 페이즈 수동 전환 |
| `/game rounds <1-3>` | 조사 라운드 수 설정 |
| `/game announce <message>` | 공지 전송 |
| `/game end` | 게임 종료 |
